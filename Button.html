How to Use

Simply add the btn-buy-now class to any anchor tag or button element with the separator line:

<a href="#" class="btn-buy-now">
    Buy Now
    <div class="separator"></div>
    <i class="fas fa-arrow-up-right arrow-icon"></i>
</a>

The button now includes the vertical separator line between the text and arrow, exactly matching your design.
